🧩 Sample Plugin (Federation Remote)

This server hosts the built plugin for Enterprise Studio.

It exposes remoteEntry.js for the host to consume — it cannot run standalone from this URL.

To develop the plugin standalone with HMR:

Run npm run dev → http://localhost:3002

To load this plugin in Enterprise Studio:

Add http://localhost:3001/remoteEntry.js as a remote plugin in Enterprise Studio settings.
